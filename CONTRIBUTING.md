# Contributing

Thanks for helping. A few rules keep this project legally clean and easy to merge.

1. **Original work only.** Do not submit code, textures, models, sounds or structures from the original LOTR Mod or any other project you don't have rights to. Playing the original mod for reference is fine; copying from it is not.
2. **Pick a ticket.** Comment on an open issue to claim it, or open one first for anything new.
3. **Follow [AGENTS.md](AGENTS.md).** Branch naming, datagen-first, package ownership and the PR checklist apply to everyone.
4. **License.** By contributing you agree your code is licensed under LGPL-3.0-only and your assets under CC BY-NC-SA 4.0.

Texture artists: match the project palette guide (coming in `docs/art.md`) and keep to 16x16 unless the spec says otherwise.

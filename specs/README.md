# Specs

Behavior specs, one file per system, written by pod leads. Implementers build **only** from these.

- Path: `specs/<pod>/<system>.md`, copied from [`_TEMPLATE.md`](_TEMPLATE.md).
- Describe behavior a player can observe: what happens, numbers, timings, edge cases.
- No code, class names, method names or assets from the original mod. Screenshots from your own playthroughs are fine.
- A spec is merged to `main` before its tickets are opened.
